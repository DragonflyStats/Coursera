# Course Description: Optimizing Spark and Cloud Data Storage for Analytics

**Program:** Open Source Data Engineering with Spark, dbt & Airflow Professional Certificate (Coursera)  
**Format:** 11 Modules | 20 Graded Assignments | Hands-on Un-graded Labs

---

## Overview
This course focuses on advanced performance optimization techniques for large-scale distributed data processing using Apache Spark and modern cloud storage architectures. Learners diagnose and resolve bottlenecks in petabyte-scale data systems, implement strategic partitioning and caching strategies to achieve 30%+ runtime improvements, build transactional data lakes using Delta Lake, and provision secure, cost-effective cloud infrastructure using Infrastructure as Code (Terraform).

---

## Core Learning Objectives
* **Spark Performance Optimization:** Analyze Spark UI metrics and distributed execution plans to eliminate shuffle and data skew bottlenecks through strategic partitioning, caching, broadcast joins, and configuration tuning.
* **Transactional Data Lakes:** Implement Delta Lake architectures to support ACID transactions, atomic writes and deletes, schema evolution, historical versioning (time travel), and data rollbacks.
* **Cloud Data Infrastructure & Security:** Provision encrypted, network-isolated cloud storage and apply least-privilege IAM policies using Terraform.
* **Storage Format Benchmarking:** Evaluate columnar versus row-oriented storage formats (Parquet, ORC, Avro) to optimize analytical query performance and reduce cloud storage costs.

---

## Tools & Technical Skills
* **Core Tools:** Apache Spark, PySpark, Delta Lake, Terraform
* **Key Competencies:** Distributed Computing Optimization, Execution Plan Analysis, Data Lake Architecture, Cloud Security & IAM, Infrastructure as Code (IaC), Storage Format Benchmarking

---

## Course Structure (11 Modules)
1. **Spark Performance Analysis & Spark UI:** Systematic performance analysis and bottleneck identification using Spark UI metrics. *(3 videos, 1 reading, 1 assignment)*
2. **Partitioning & Caching Strategies:** Implementing partitioning and caching to accelerate distributed processing. *(3 videos, 1 reading, 2 assignments, 1 ungraded lab)*
3. **Distributed Execution Plans:** Analyzing execution plans to diagnose data shuffle and skew patterns. *(3 videos, 3 readings, 1 assignment, 1 ungraded lab)*
4. **Advanced Spark Optimization:** Resolving bottlenecks via partition tuning, broadcast joins, and configuration optimization. *(1 video, 1 reading, 3 assignments)*
5. **Transactional Data Lake Foundations:** ACID transactions, versioning fundamentals, and converting Parquet tables to Delta format. *(2 videos, 1 reading, 2 assignments)*
6. **Delta Lake Operations & Auditing:** Executing conditional atomic writes/deletes, querying historical table versions, and verifying rollbacks. *(2 videos, 2 assignments, 1 ungraded lab)*
7. **Cloud Security & IaC Principles:** Encryption methods, access control concepts, and secure data infrastructure design. *(3 videos, 1 reading, 2 assignments)*
8. **Provisioning Secure Infrastructure with Terraform:** Implementing encrypted cloud storage, access controls, and network isolation using Terraform. *(2 videos, 1 reading, 2 assignments, 1 ungraded lab)*
9. **Storage Format Fundamentals:** Evaluating trade-offs between columnar and row-oriented storage formats for analytical workloads. *(3 videos, 1 reading, 1 assignment)*
10. **Storage Format Benchmarking:** Conducting performance benchmarks across formats (Parquet, ORC, Avro) to produce architecture recommendations. *(1 video, 2 readings, 3 assignments)*
11. **Capstone Project:** End-to-end data infrastructure optimization project integrating Spark tuning, Terraform security provisioning, and storage architecture evaluation. *(4 readings, 1 assignment)*
