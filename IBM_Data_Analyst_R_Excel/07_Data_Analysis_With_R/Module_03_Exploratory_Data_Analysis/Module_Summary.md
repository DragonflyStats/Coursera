Exploratory data analysis is an approach to analyzing data that summarizes its main characteristics and helps you gain a better understanding of the dataset, uncover relationships between different variables, and extract important variables for the problem you are trying to solve. 

Descriptive statistics describe basic features of data and generate short summaries about the sample and measures of the data. Using boxplots and scatter plots, you can visualize data distribution and relationships in a visual way. 

Grouping and sorting categorical data can help you answer questions about it, especially when you visualize it using a plot, like a heatmap. 

Using an ANOVA test helps you find correlations between different groups of a categorical variable and determine the strength of the correlation by examining the F-test score and P-score. 

Correlation measures to what extent different variables are interdependent. 

A positive correlation is a relationship between two variables in which both variables move in the same direction. 

The Pearson correlation measures the strength of the correlation between two or more variables.
