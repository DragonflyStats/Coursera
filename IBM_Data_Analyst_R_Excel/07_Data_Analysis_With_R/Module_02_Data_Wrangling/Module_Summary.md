Data pre-processing (or data wrangling) is the process of converting or mapping data from the initial “raw” form into another format to prepare the data for further analysis.  

You can handle missing data by dropping or replacing the missing values, working with the source of the data to either determine what the missing values should be or provide a better source of data, or leave the missing values in place. 

You can reformat data to bring it into a common standard of expression, which helps you make meaningful comparisons. 

You can reformat an entire column by using the separate() function or correct data types by using the mutate_all() and mutate_if() functions. 

Normalization is a way to bring all data into a similar range, for more meaningful comparison.  

A few of the most common ways to normalize data include simple feature scaling, Min-Max, and Z-score. 

Binning can improve the accuracy of predictive models and help you better understand the distribution of your data.  

One binning approach divides numerical values into quartiles to improve data analysis. 

You can turn categorical values to numeric values by using a technique called “one-hot encoding”.
