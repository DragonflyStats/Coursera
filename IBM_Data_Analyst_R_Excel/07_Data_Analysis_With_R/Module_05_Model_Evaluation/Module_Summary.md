Congratulations! You have completed this lesson. At this point in the course, you know:  

An important part of model evaluation is separating data into training and testing sets. 

There are three steps to evaluating a model: Train the model, make predictions, and compute metrics.  

Cross validation techniques, like n-fold cross validation, can help improve the evaluation of models when datasets are small. 

The bias-variance trade-off is finding the right balance between overfitting and underfitting.  

You can prevent overfitting and underfitting models by changing the model complexity and employing other strategies. 

Regularization is a technique you can use to avoid overfitting by restricting the magnitude of model coefficients.  

A grid search makes the process of tuning the hyperparameters in your models easier by training a new model for every parameter that you specify and finding the value of the parameter that has the smallest error.
