# Course 1: Modern Data Architecture Fundamentals with Microsoft Fabric

### Key Overview

* **Course Position:** Course 1 of 5 in the Professional Certificate series.
* **Provider & Instructor:** Microsoft (via Coursera).
* **Level & Pacing:** Intermediate level; estimated at **3 weeks to complete** at **10 hours per week** (approx. 27 total instruction hours).
* **Structure:** Comprises 5 individual modules and 60 assessments.

---

### What the Course Covers

The course focuses on the conceptual and architectural foundation of modern data stacks, tracing the evolution from legacy data warehouses to cloud-native lakehouse models.

#### Core Topics & Focus Areas

* **Architectural Evolution:** Moving from traditional data warehousing to modern cloud-native lakehouses.
* **Microsoft Fabric Architecture:** Exploring core Fabric components and building modular architectures.
* **OneLake Setup:** Setting up and configuring OneLake as a single unified storage foundation across an enterprise.
* **Data Virtualization & Formats:** Working with diverse data formats and applying advanced virtualization techniques.
* **Blueprint Design:** Creating a comprehensive modern data architecture blueprint.

---

### Skills Acquired

* **Data Architecture & Design:** Building scalable enterprise architectural blueprints.
* **Data Storage & Lakes:** Setting up OneLake and managing cloud-native storage.
* **Virtualization & Integration:** Abstracting and integrating multi-source data without unnecessary movement.
* **Governance & Metadata:** Managing metadata, schemas, and data governance frameworks.
