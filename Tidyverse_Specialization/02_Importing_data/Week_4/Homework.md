Homework
========================

#### Introduction and Background

All data science projects require you to import data into a statistical analysis system like R. 
Data can come from a wide variety of sources in similarly wide variety of formats. 
It is the data scientist's job to import that data, harmonize different datasets, and organize the data to prepare it for analysis. 

In this course we have learned about different data formats and the tools for importing data from those formats.
In this project you will need to import data from three different formats and compute some basic summary statistics from the imported data.
