Module Assignment
========================

In this project, you will practice data exploration and data wrangling with the tidyverse using consumer complaint data from the Consumer Financial Protection Bureau (CFPB).

#### Learning Objectives
* Apply the tidyr package to reshape tidy data
* Apply the functions in the dplyr package to build data processing pipelines
* Apply the forcats package to manipulate factor data
* Apply the lubridate package to manipulate date and time data
* Use the stringr package to apply regular expressions to text data
* Apply the tidytext package for sentiment analysis
