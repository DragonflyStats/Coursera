##### Question 1

* **Question Restatement:** What is the goal of supervised learning?
* **Options Listing:**
* A. Predict the features.
* B. Predict the labels.
* C. Find the target.
* D. Find an underlying structure of the dataset without any labels.


* **Correct Answer Indication:** **B. Predict the labels.**
* **Explanation/Rationale:** Supervised learning algorithms learn a function that maps input features to a known target output or discrete categorical label.

##### Question 2

* **Question Restatement:** What is deep learning?
* **Options Listing:**
* A. Deep learning is machine learning that involves deep neural networks.
* B. Deep learning is another name for artificial intelligence.
* C. Deep learning includes artificial intelligence and machine learning.
* D. None of the above are correct.


* **Correct Answer Indication:** **A. Deep learning is machine learning that involves deep neural networks.**
* **Explanation/Rationale:** Deep learning is a specialized subset of machine learning that utilizes complex, multi-layered artificial neural networks to model abstract representations in data.

---

##### Question 3

* **Question Restatement:** When is a standard machine learning algorithm usually a better choice than using deep learning to get the job done?
* **Options Listing:**
* A. When working with small data sets.
* B. When the data is steady over time.
* C. When working with large data sets.
* D. None of the above are correct.


* **Correct Answer Indication:** **A. When working with small data sets.**
* **Explanation/Rationale:** Deep learning models require massive volumes of data and heavy computational power to train effectively without overfitting. For smaller datasets, traditional machine learning algorithms usually yield better generalization with significantly lower resource overhead.

##### Question 4

* **Question Restatement:** What is a Turing test?
* **Options Listing:**
* A. It tests images.
* B. It tests a machine's ability to exhibit intelligent behavior.
* C. It tests and cleans the dataset.
* D. It tests the dataset.


* **Correct Answer Indication:** **B. It tests a machine's ability to exhibit intelligent behavior.**
* **Explanation/Rationale:** Proposed by Alan Turing in 1950, the Turing Test is a foundational benchmark designed to evaluate whether a machine can exhibit human-like intelligent behavior and conversation.

##### Question 5

* **Question Restatement:** What are some of the different milestones in deep learning history?
* **Options Listing:**
* A. Deep Blue defeats a world champion chess player, and Keras is released.
* B. Geoffrey Hinton’s work, AlexNet, and TensorFlow
* C. Deep Blue defeats a world champion chess player and TensorFlow is released
* D. Deep Blue defeats a world champion chess player, and AlexNet is created.


* **Correct Answer Indication:** **B. Geoffrey Hinton’s work, AlexNet, and TensorFlow**
* **Explanation/Rationale:** Key milestones in deep learning history include Geoffrey Hinton's work on unsupervised pre-training (2006), the AlexNet convolutional neural network victory (2012), and the release of the TensorFlow framework (2015). Deep Blue represents a milestone in symbolic chess AI rather than deep learning.

##### Question 6

* **Question Restatement:** What is artificial intelligence?
* **Options Listing:**
* A. A subset of deep learning.
* B. Any program that can sense, reason, act, and adapt.
* C. A subset of machine learning
* D. None of the above.


* **Correct Answer Indication:** **B. Any program that can sense, reason, act, and adapt.**
* **Explanation/Rationale:** Artificial Intelligence is the broad umbrella discipline encompassing any computer program or system engineered to sense environment inputs, reason, act, and adapt to perform tasks that typically require human intelligence.

* **Options Listing:**
* A. Deep learning and machine learning.

##### Question 8

* **Question Restatement:** Why did AI flourish so much in the last years?
* **Options Listing:**
* A. Data storage in the cloud is much more expensive
* B. Stylish designed computers
* C. Faster and inexpensive computers and data storage
* D. Access to hardware for cleaning data


* **Correct Answer Indication:** **C. Faster and inexpensive computers and data storage**

* **Options Listing:**
* A. Recognizes faces and pictures.
* B. Recognizes our voice and answers questions.
* C. Suggests who a person on a photo is.
* D. None of the above answers are correct.

* **Options Listing:**
* A. Problem statement and data cleaning.
* B. Problem statement and data collection.
* C. Data collection and data transformation.
* D. None of the above answers is correct.
