Instructions

You will upload your .r file as your submission.

Review criteria

A classmate will download your .r file and compare the output generated by your file against the output in the solution key.

Step-By-Step Assignment Instructions

Download the .r file attached to these instructions.

Download the PDF solution key attached to these instructions.

Open the .r file in RStudio and the PDF file in a PDF viewer on your computer. Make sure you download the .csv file to a location that you can locate on your computer when you import it into R.
