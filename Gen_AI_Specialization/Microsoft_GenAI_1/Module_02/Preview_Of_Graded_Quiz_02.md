# Topics Covered: Getting Started with Generative AI in Azure

This quiz assesses understanding of the fundamental concepts involved in designing, building, evaluating, and improving generative AI applications using Microsoft Foundry and Azure AI services.

## Application Design and Planning

- Defining the purpose and goals of a generative AI application.
- Identifying required inputs and expected outputs.
- Determining application functions and user requirements before development begins.
- Establishing a framework for AI-powered applications such as chatbots, summarisers, and text generators.

## Microsoft Foundry Components

- Understanding the role of the **Model Catalog**.
- Knowing how AI models are accessed and integrated into applications.
- Recognising the different components involved in building generative AI solutions.

## Prompt Engineering

- Using prompts to guide model behaviour and output quality.
- Improving generated content by adding context, examples, constraints, and desired formats.
- Modifying prompts based on testing results and user needs.
- Understanding prompt engineering as a primary method for controlling model outputs.

## Model Evaluation and Testing

- Assessing whether generated outputs meet business requirements.
- Testing applications using realistic inputs and use cases.
- Evaluating outputs for:
  - Accuracy
  - Relevance
  - Completeness
  - Clarity
  - Appropriateness
  - Tone and style
- Using subject matter experts and business criteria to judge output quality.

## Quality Assurance and Iterative Improvement

- Conducting regular testing throughout development.
- Identifying and correcting issues before deployment.
- Comparing generated outputs against project standards and expectations.
- Using feedback and evaluation results to improve application performance.

## Fine-Tuning and Model Customisation

- Understanding the purpose of fine-tuning.
- Using domain-specific examples and training data.
- Improving consistency, style, and subject-matter relevance.
- Adapting model behaviour to specific business or application contexts.

## Performance Improvement Strategies

- Refining prompts to achieve better results.
- Incorporating examples from intended use cases.
- Using an iterative cycle of testing, reviewing, and adjusting.
- Maintaining quality as new features and updates are introduced.

## Responsible Evaluation of Generated Content

- Determining whether an AI solution successfully accomplishes its intended purpose.
- Evaluating outputs against organisational standards and guidelines.
- Measuring success based on user needs rather than technical metrics alone.
- Validating that generated content is useful, appropriate, and aligned with business objectives.

## Knowledge Expected

By completing this quiz, a learner should be able to:

- Explain the basic workflow for developing a generative AI application.
- Identify the role of Microsoft Foundry's Model Catalog.
- Apply prompt engineering techniques to improve AI-generated content.
- Describe how fine-tuning can improve model performance.
- Design suitable testing and evaluation approaches for generative AI applications.
- Recognise characteristics of high-quality AI-generated outputs.
- Use iterative improvement methods to enhance application performance.
- Judge whether a generative AI solution is meeting its intended business goals.
- Distinguish between prompt engineering, testing, evaluation, and fine-tuning as separate but complementary optimisation techniques.
