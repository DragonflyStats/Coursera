### Question 1

Carlos has just started a new project in Microsoft Foundry and wants to test a text generation model in the Chat Playground. He needs to select a model, review the parameters, and run a test prompt. In which order should he complete these steps?

* **A)** Review parameters, run a test prompt, then select a model deployment
* **B)** Run a test prompt with the default model, then select a different model if the response is unsatisfactory
* **C)** Adjust parameters first, then select a model deployment, then run a test prompt
* **D)** Open the Chat Playground, select a model deployment from the Model Catalog, review and adjust parameters, then run a test prompt **(Correct Answer)**

> **Explainer:** To test models effectively in the Chat Playground, users must first open the platform, establish or select a model deployment from the catalog, configure parameters as needed, and finally execute test prompts.

### Question 4

Luc ran three experiments in Microsoft Foundry, changing the learning rate in each run: 0.001, 0.01, and 0.1. The experiment with a learning rate of 0.01 produced the best accuracy. He now wants to confirm this is the optimal setting before finalizing. What is the most rigorous next step? Select the best answer.

* **A)** Run additional experiments with learning rates between 0.001 and 0.01 and between 0.01 and 0.1 to refine the search. **(Correct Answer)**
* **B)** Accept 0.01 as optimal since it outperformed the other two tested values.
* **C)** Deploy the model immediately since it achieved the best results in the current test.
* **D)** Switch to a different model type, as the current model may not be suited to this dataset.

> **Explainer:** To rigorously verify model hyperparameters and narrow down optimal performance, running finer-grained intermediate evaluations between successful search boundaries is standard machine learning best practice.
