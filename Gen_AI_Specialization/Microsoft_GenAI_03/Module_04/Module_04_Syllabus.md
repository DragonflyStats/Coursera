# Course Syllabus: Generative AI Coursework & Notebook Analysis

## Component 1: Generative AI Fundamentals & Model Evolution

* **Topic 1.1:** Distinguishing generative models (synthesizing new, original content) from discriminative models (classifying and analyzing existing data distributions).


* **Topic 1.2:** Transitioning from traditional human-coded rule systems (traditional programming) to data-driven Machine Learning and multi-layered Deep Learning neural networks.


* **Topic 1.3:** Exploring multi-modal capabilities across text, code, images, audio, and video creation.


* **Topic 1.4:** Sequential data generation, autoregressive time-series forecasting, and overcoming long-context limitations via Recurrent Neural Networks (RNNs), LSTMs, and Transformer self-attention architectures.



## Component 2: Advanced Prompt Engineering & Design Patterns

* **Topic 2.1:** Anatomy of an effective prompt (defining core structural building blocks such as instructions, background context, input data, and output format indicators).


* **Topic 2.2:** Core prompting methodologies, including zero-shot prompting, few-shot exemplar framing, and targeted contextual guidance.


* **Topic 2.3:** Advanced design patterns, such as the **Persona Pattern** (guiding tone, voice, and perspective) and the **Interview Pattern** (interactive step-by-step dialogue).


* **Topic 2.4:** Advanced reasoning frameworks, covering **Chain-of-Thought (CoT)**, **Tree-of-Thought (ToT)**, and the **Playoff Method** (generation and self-evaluation).



## Component 3: Retrieval-Augmented Generation (RAG) Architecture & Implementation

* **Topic 3.1:** Fundamentals of RAG pipelines for grounding LLMs in secure, dynamic, and up-to-date external knowledge bases.


* **Topic 3.2:** Document preprocessing pipelines, including data cleaning, logical chunking, and vector embedding generation.


* **Topic 3.3:** Vector database storage and indexing infrastructure utilizing **Azure AI Search**.


* **Topic 3.4:** Advanced retrieval optimizations, including **Hybrid Search** (combining keyword and vector search) and post-retrieval **Reranking**.



## Component 4: Model Customization, Fine-Tuning & Hybrid Strategies

* **Topic 4.1:** The strategic decision framework: evaluating when to use prompt engineering, RAG, Supervised Fine-Tuning (SFT), or hybrid approaches.


* **Topic 4.2:** Preparing and validating structured training datasets consisting of prompt-response pairs for domain adaptation and brand voice consistency.


* **Topic 4.3:** Executing fine-tuning jobs in Microsoft Foundry / Azure AI Studio (selecting base models, managing hyperparameters, and analyzing loss curves).


* **Topic 4.4:** Implementing hybrid architectures (fine-tuning for specialized technical jargon or personas combined with RAG for real-time factual retrieval).



## Component 5: Application Development, Evaluation, and Responsible AI

* **Topic 5.1:** Designing high-level application architectures, managing APIs, and orchestrating workflows using **Prompt Flow**.


* **Topic 5.2:** Evaluating RAG pipeline performance using specialized metrics (**Faithfulness**, **Context Precision**, and **Context Recall**).


* **Topic 5.3:** Core principles of Responsible AI (Transparency, Accountability, Fairness, Privacy & Security, Reliability & Safety, and Inclusiveness).


* **Topic 5.4:** Cybersecurity and threat mitigation: configuring Azure AI Content Safety filters, deploying **Prompt Shields**, and preventing direct/indirect prompt injection attacks.
