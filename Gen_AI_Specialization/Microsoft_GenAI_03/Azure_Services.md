## Azure and AI Foundry services

* **Azure AI Foundry (formerly Azure AI Studio):** An enterprise platform and unified control center for building, testing, evaluating, and deploying generative AI applications, prompt flows, and custom models.
* **Model Catalog:** A curated hub within Azure AI Foundry where developers can browse, evaluate, select, and deploy pre-built foundational models (such as OpenAI's GPT models and open-weights models) to power their applications.
* **Azure AI Search:** An enterprise-grade cloud search service that provides data ingestion, indexing, and scalable querying capabilities, serving as the core retrieval engine for RAG (Retrieval-Augmented Generation) pipelines.
* **Prompt Flow:** A developer tool within Azure AI Foundry designed to streamline the lifecycle of LLM-based apps by providing a visual graph interface to link prompts, data sources, and custom logic into executable workflows.
* **Azure AI Content Safety:** A safety service that automatically detects and blocks harmful content (such as hate speech, violence, and self-harm) in both input prompts and generated model responses using configurable severity filters.
* **Prompt Shields:** Built-in security mechanisms specifically engineered to detect and intercept adversarial attacks, including direct jailbreaks and indirect prompt injections.
* **Azure Monitor:** A centralized monitoring service used to collect telemetry, track operational performance metrics, and log system health data for deployed cloud applications.
* **Azure Blob Storage & SQL Database:** Cloud storage and database services utilized for securely managing unstructured data files (like training documents and PDFs) and structured relational data assets.
