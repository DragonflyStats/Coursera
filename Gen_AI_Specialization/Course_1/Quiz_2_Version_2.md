## Graded Quiz: Tools for Generative AI

### Question 1

How will ChatGPT respond if you ask it to create slides on “the impact of deforestation on biodiversity”?

* **A)** It will generate an outline.
* **B)** It will summarize scientific studies.
* **C)** It will suggest the slides’ title, content, and visuals. **(Correct Answer)**
* **D)** It will generate a word-for-word lecture script.

> **Explainer:** When prompted for slide creation, generative text tools like ChatGPT can provide structured breakdowns, including suggested slide titles, bulleted content, and visual descriptions.

* **B)** Automatically deploy code to cloud environments

### Question 7

Which of the following best describes how large language models (LLMs) generate meaningful text?

* **A)** By randomly combining words from previous inputs
* **B)** By extracting phrases from publicly available articles
* **C)** By referencing a fixed database of pre-written answers
* **D)** By using language patterns to predict responses **(Correct Answer)**

> **Explainer:** LLMs generate coherent, contextually relevant text by analyzing statistical language patterns learned during training to predict subsequent tokens.
