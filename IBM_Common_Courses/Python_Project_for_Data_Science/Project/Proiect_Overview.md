# Project Overview

In this project, you will take on the role of a Data Scientist or Data Analyst working for a startup investment firm. The firm helps customers make informed decisions about investing in stocks.

Your task is to extract financial data—such as historical stock prices and quarterly revenue—from multiple sources using Python libraries and web scraping techniques. You will then visualize this data in a dashboard to identify patterns and trends.

You will work with the following stocks:

* Tesla 

* Amazon 

* AMD 

* GameStop 

### Dashboard Analytics
A dashboard helps present key insights in a clear and interactive way. In this project, you will:

* Analyze datasets and extract meaningful insights 

* Use prompts to access and process data effectively 

* Create visualizations using Plotly 

* Present your findings in a well-structured dashboard 

### Submission and Evaluation
You will submit your work through an AI-graded assignment.

### Review Criteria

* Completion of two hands-on labs on extracting stock data 
* Completion of two quizzes to test your understanding 

 Submission of the final assignment, including screenshots and results from your work
