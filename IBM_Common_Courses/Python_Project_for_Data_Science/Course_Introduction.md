## Course Introduction

**Welcome to this Python project mini-course!**

This course builds on the skills you learned in ***Python for Data Science, AI and Development***  and gives you a chance to apply them in a hands-on project.

In this course, you will take on the role of a Data Scientist or Data Analyst. You will work with real-world data and perform tasks such as data extraction, web scraping, data visualization, and dashboard creation.

* Module 1: Learn the basics of data collection and web scraping, including working with HTML and extracting stock data from different sources. 

* Module 2: Learn how to analyze and visualize stock data to identify trends and gain insights. 

Note: If you completed an older version of ***Python for Data Science, AI and Development***  course that did not include web scraping, please review the lesson on Web Scraping in Module 1 before you begin.

At the end of the course, you will submit your project for AI-based grading.

To succeed, you should have basic knowledge of Python and working with data.
