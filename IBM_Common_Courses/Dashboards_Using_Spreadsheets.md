**Graded Quiz: Creating Dashboards using Spreadsheets**

---

### **Question 1 / 4** (1 point)

**Extracted Text:**

> Which one of the following statements best describes the main purpose of a digital dashboard?
> * To display all your charts in one location.
> * To provide a static data-findings report of your business data.
> * To display the most important or relevant information in a single place.
> * To analyse different types of data.
> 
> 

**Analysis & Solution:**

* **Correct Answer:** **To display the most important or relevant information in a single place.**
* **Explanation:** Dashboards are designed to consolidate key metrics, KPIs, and high-priority insights into a single, easy-to-read view so stakeholders can quickly monitor performance and make decisions—rather than dumping *all* charts, acting as a static report, or serving as a raw data-analysis workspace.

### **Question 2 / 4** (1 point)

**Extracted Text:**

> According to the ‘Creating a Simple Dashboard using Excel’ video, what did subject matter experts advise when building dashboards?
> * Bright colors highlight key points.
> * Having as many visualizations as possible can help you clearly define your key points.
> * Displaying too much information means your key points can get lost.
> * Use numbers as much as possible to help focus users on your key points.
> 
> 

**Analysis & Solution:**

* **Correct Answer:** **Displaying too much information means your key points can get lost.**
* **Explanation:** A core principle of effective dashboard design is visual simplicity and focus. Overcrowding a dashboard with excessive charts, numbers, or overly bright colors creates clutter and distracts viewers from the primary takeaways.

### **Question 3 / 4** (1 point)

**Extracted Text:**

> Which feature in Excel enables you to precisely control what information is displayed in a visualization such as a chart?
> * Sorting
> * Filters
> * Pivot Tables
> * Sparklines
> 
> 

**Analysis & Solution:**

* **Correct Answer:** **Filters**
* **Explanation:** **Filters** (including Chart Filters and Slicers) allow you to selectively include or exclude specific data series, categories, or values displayed within a chart. *(Note: Sorting reorders data, Pivot Tables summarize/aggregate datasets, and Sparklines are miniature inline cell charts).*

### **Question 4 / 4** (1 point)

**Extracted Text:**

> Which of the following tasks should you perform before creating a dashboard? *(Select all that apply)*
> * [ ] Format the data as a table
> * [ ] Remove blank data rows
> * [ ] Format the data as a CSV file
> * [ ] Create visualizations
> 
> 

**Analysis & Solution:**

* **Correct Answers:**
* ☑ **Format the data as a table**
* ☑ **Remove blank data rows**


* **Explanation:** Before building visualizations or a dashboard in Excel, you must clean and structure your raw dataset. **Removing blank data rows** prevents broken ranges and inaccurate aggregations, while **formatting the data as an Excel Table** ensures dynamic range expansion and clean structured references when building Pivot Tables and charts. *(Formatting as a CSV strips Excel formatting/formulas, and creating visualizations is part of building the dashboard itself rather than a prerequisite preparation step).*
