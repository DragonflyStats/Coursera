###### Question 1

1. **Question Restatement:** SQL is what type of database management system?
2. **Options Listing:**
* Object-oriented
* Relational
* Hierarchical
* Network


3. **Correct Answer Indication:** **Relational**
4. **Explanation/Rationale:** SQL (Structured Query Language) is designed specifically for managing data in Relational Database Management Systems (RDBMS), where data is structured into tables composed of rows and columns governed by schemas.

###### Question 2

1. **Question Restatement:** Which of these is a machine learning or deep learning library for Python?
2. **Options Listing:**
* Pandas
* NumPy
* Scikit-learn
* Requests


3. **Correct Answer Indication:** **Scikit-learn**
4. **Explanation/Rationale:** Scikit-learn is the standard Python open-source library built for machine learning, offering implementations for classification, regression, and clustering algorithms. Pandas and NumPy handle data manipulation/arrays, while Requests handles HTTP web connections.

###### Question 3

1. **Question Restatement:** Generally speaking, which type of model is used to predict a numerical value, such as the potential sales price of a used car?
2. **Options Listing:**
* Clustering model
* Regression model
* Classification model


3. **Correct Answer Indication:** **Regression model**
4. **Explanation/Rationale:** Regression algorithms predict continuous numerical outputs (such as monetary prices, height, or temperatures). Classification models predict discrete categorical labels, and clustering models group unlabeled observations without a target variable.

###### Question 8

1. **Question Restatement:** Which of the following statements about Jupyter Notebook is correct?
2. **Options Listing:**
* Jupyter Notebook supports the Visualization of data in charts.
* Jupyter Notebook provides storage of massive quantities of data in data lakes.
* Jupyter Notebook is only available if installed locally on your computer.
* Jupyter Notebook is a commercial product of IBM.


3. **Correct Answer Indication:** **Jupyter Notebook supports the Visualization of data in charts.**
4. **Explanation/Rationale:** Jupyter Notebooks natively integrate inline plotting and visualization rendering (such as displaying Matplotlib, Seaborn, or Bokeh charts directly below code cells). It is open-source (Project Jupyter) rather than an IBM product, runs both locally and in the cloud, and is an execution UI rather than a data lake storage solution.

###### Question 9

1. **Question Restatement:** What is the purpose of dplyr library in R?
2. **Options Listing:**
* Data Manipulation
* Data Visualization
* String Manipulation
* Machine learning


3. **Correct Answer Indication:** **Data Manipulation**
4. **Explanation/Rationale:** `dplyr` is a core package in R's Tidyverse designed specifically for data manipulation, providing verbs like `filter()`, `select()`, `mutate()`, `summarize()`, and `arrange()`.

###### Question 10

1. **Question Restatement:** Which feature of GitHub is a way of proposing changes to main branch?
2. **Options Listing:**
* All of the above
* Pull Request
* Cloning
* Fork


3. **Correct Answer Indication:** **Pull Request**
4. **Explanation/Rationale:** A Pull Request (PR) on Git platforms like GitHub is the mechanism used to notify collaborators of changes pushed to a branch, allowing team members to review, discuss, and merge those proposed changes into the main branch.

2. **Options Listing:**
* GoogleColab
* All of the above
* Spider
* VScode
* Jupyterlite


3. **Correct Answer Indication:** **Jupyterlite**

###### Question 12

1. **Question Restatement:** Which among the following is not a feature of Googlecolab?
2. **Options Listing:**
* Execute on browser
* Upload and share with setup and installation
* Can be stored on Google drive
* Clone from GitHub and execute in GoogleColab


3. **Correct Answer Indication:** **B. Upload and share with setup and installation**
4. **Explanation/Rationale:** Google Colab is completely hosted in the cloud and requires **zero setup or installation** to run or share notebooks. Users can simply share a link without requiring collaborators to perform any manual environment installation steps.
