### **Question 2**

**A developer is working on a lightweight time-series prediction task using a small dataset. Each output must be predicted based on the previous ones using a step-by-step sequence generation without needing large context windows. Which neural network architecture is most appropriate?**

* **Your Answer:** **Recurrent neural networks (RNNs)** (Correct)


* **Summary:** RNNs maintain an internal recurrent hidden state that carries sequential information step-by-step from one time step to the next, making them ideal for lightweight sequence tasks without heavy attention window overhead.

### **Question 3**

**Kate wants to build a chatbot that produces coherent responses in conversations. She looks for a model that acts primarily as a decoder to generate natural text. Which large language model (LLM) is best suited for this?**

* **Your Answer:** **Generative pretrained transformer (GPT)** (Correct)


* **Summary:** GPT uses a decoder-only autoregressive transformer architecture built specifically for next-token prediction and fluent conversational text generation (unlike BERT, which is encoder-only, or BART/T5, which are encoder-decoder models).
