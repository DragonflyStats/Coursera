The IBM Professional Certificate in Data Engineering consists of 16 courses:

1. **Data Engineering Basics for Everyone**
2. **Python Basics for Data Science** (Website: https://www.coursera.org/learn/python-for-applied-data-science-ai)
3. **Python for Data Engineering Projects**
4. **Relational Database Basics**
5. **SQL for Data Science**
6. **SQL Concepts for Data Engineers**
7. **Linux Commands & Shell Scripting**
8. **Relational Database Administration (DBA)**
9. **Building ETL and Data Pipelines with Bash, Airflow, and Kafka**
10. **Data Warehousing and BI Analytics**
11. **NoSQL Database Basics**
12. **Big Data, Hadoop, and Spark Basics**
13. **Apache Spark for Data Engineering and Machine Learning**
14. **Data Engineering Capstone Project**
15. **Job Outlook**
