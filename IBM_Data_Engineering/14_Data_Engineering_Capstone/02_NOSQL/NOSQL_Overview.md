# Assignment Overview: Querying Data in NoSQL Databases
***Set up your NoSQL Data Repository***

### Assignment Overview
In this assignment, you will complete a series of tasks within a single exercise. Before beginning, you will install mongoimport and mongoexport in the lab environment and download the provided JSON (JavaScript Object Notation) file.

The exercise requires you to first import the JSON file into the MongoDB server, creating a database and a collection named electronics. After importing the data, you will list all databases and display the collections available in the database catalog.

Next, you will retrieve and display the first five documents from the collection. You will then write queries to:

* Count the number of laptops

* Count the number of mobile phones with a screen size of 6 inches

* Calculate the average screen size of smartphones

* Finally, you will export the ID, type, and model fields from the collection into a CSV (Comma-Separated Values) file.
